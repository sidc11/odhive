# OdHive logo

| File | Use |
|---|---|
| `odhive-wordmark.svg` | Wordmark on light backgrounds |
| `odhive-wordmark-dark.svg` | Wordmark on dark backgrounds |
| `odhive-mark.svg` | Icon only (favicon, app icon, avatar) |

The "O" is a hexagon (a hive cell) split into three segments, one per running
server, with a status light in the middle. The dot on the "i" is a small cell.

Colors: purple `#714B67` → amber `#F5A524`.
Lettering is converted to outlines from the Outfit typeface (SIL Open Font License 1.1).
